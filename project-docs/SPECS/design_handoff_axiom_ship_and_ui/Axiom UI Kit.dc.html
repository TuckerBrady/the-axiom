HUD chrome TACTICAL SCREENS ONLY
CORNER BRACKETS
Brackets at 22pt, 2pt stroke, rgba(74,158,255,0.35), inset 12–14pt. Fade in over 600ms. Gameplay, sector map, dossier, results. Never on hub, settings, store, or codex.
Proposed: brackets currently render at 0.3 alpha in the ship prototype and 0.12 on some screens. Pick one value and put it in tokens — chrome that varies per screen reads as inconsistency, not atmosphere.
